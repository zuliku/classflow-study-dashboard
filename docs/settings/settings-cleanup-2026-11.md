# Settings Cleanup · 普通用户设置清理（2026-11）

> 2026-11-05。范围：设置中心普通用户分区；开发者/演示入口未改。

## 目标

- 去掉重复控制、只读“假设置”和无作用的配置。
- 统一容易误解的文案。
- 只新增真正缺少、且已有底层能力的设置。

## 移除 / 降级

| 项 | 处理 |
| --- | --- |
| 通用 → 侧栏收起状态 | 删除。侧栏左下角按钮是唯一控制，Settings 不再镜像同一 state。 |
| 任务 → 应用内提醒 | 删除行；改为“通知与提醒”分组说明“站内提醒始终开启”。 |
| 专注 → 实时专注计时 | 删除行；改为“专注会话”分组说明。 |
| Kiro → 搜索服务 | 删除只读状态行；搜索服务状态合并进“凭据”描述。 |
| Agent → 安全边界 | 删除只读行；改为“权限与安全”分组说明。 |
| 数据 → 隐私 3 行 | 合并为一张“隐私”说明卡，保留 3 个搜索 target。 |

## 合并 / 修正

- “临近截止提醒” → **“临近截止范围”**：只控制总览/课表速览显示窗口，不发送通知。
- “浏览器系统通知” → **“系统通知”**：明确同时覆盖提醒与专注完成。
- 免打扰文案明确“只影响提醒，不影响专注完成提示”。
- API Key 与“测试连接”合并为同一行。
- 搜索凭据与“测试连接”合并为同一行。
- 关闭“课程自动配色”时，课程调色板禁用并说明原因。

## 新增

| 设置 | 说明 |
| --- | --- |
| 提醒音量 + 试听 | `ReminderPreferences.reminderSoundVolume`（0–100，默认 100 保持既有听感）。 |
| 专注期间自动免打扰 | 专注 session running 时暂停提醒的系统通知与声音。 |
| Kiro 发送方式 | Enter 发送 / Ctrl+Enter 发送；Shift+Enter 始终换行。 |
| Kiro 浮动面板重置 | 只重置 Sidecar 几何，不影响其它偏好。 |
